# To_Do_List-Web-app
This project is a simple To-Do List web application created using HTML, CSS, and JavaScript. It helps users add daily tasks, mark them as completed, and delete them when finished. The project uses basic front-end technologies, so it is easy to understand and suitable for beginners.

The index.html file contains the basic structure of the application. It defines the input field, add button, and task list area. This file also connects the CSS file for styling and the JavaScript file for functionality. It works as the main page of the application.

The style.css file is used to design the application. It adds colors, layout, fonts, and spacing to make the app clean and user-friendly. It also shows completed tasks with a line-through effect. This file controls the visual appearance of the app.

The script.js file handles the main logic of the application using JavaScript. It allows users to add tasks, mark tasks as done, and remove tasks. It also saves tasks in the browser using localStorage so the data is not lost after refreshing the page. This makes the application interactive and useful.

Overall, the project clearly separates structure, design, and functionality. HTML is used for structure, CSS for styling, and JavaScript for logic. The main idea of this project is to create a simple task manager that runs in the browser without using any backend.
